# 00-开发总纲

## 1. 项目定位与架构宪章

本项目构建一台**面向自主学习的本地优先、云端增强型随身学习终端**（硬件采用 `ESP32-S3-CAM N16R8` + `3.5 寸 320×480 竖屏`，云端采用树莓派 4B 无状态算力网关）。

### 核心架构铁律（不可违背）
1. **Local-First + Cloud-Assist（本地优先、云端辅助）**：
   * 外部 TF 卡（`/sdcard`）是设备唯一真实数据源，板载 `LittleFS` 仅存放只读中文字库、内置提示音 `ding.wav` 及静态 UI 图标；
   * 树莓派 4B 网关不维护重型双端同步数据库，仅承担安全鉴权、多模态 AI 路由推理、云端 ASR/TTS 音频中转缓存（`16kHz WAV`）、离线学科包加密打包及轻量 Web 管理控制台职能；
   * 断网状态下，本地题库刷卡、纯本地电子书阅读、番茄钟、本地课表查看与准点提醒、以及离线拍题/语音暂存队列（`/outbox/`）必须 100% 独立可用。
2. **奥卡姆剃刀（极简主义工程边界）**：
   * 硬件全机仅保留**双轴按键摇杆**作为唯一物理输入件，零触屏、零多余按键群；
   * 单片机固件严禁引入重型文件解析库（如 `.epub` / `.pdf` / `GBK` 转码）或本地语音合成算法；所有格式清洗与语音识别/合成全部收敛在云端完成；
   * 树莓派 Web 管理台采用**零构建单文件架构**（`web/index.html`），不引入 Node.js / Webpack / React 构建链。
3. **防依赖教学与温和交互底线**：
   * 拍题导学强制执行“草稿痕迹初筛 $\rightarrow$ 阶梯拆解 $\rightarrow$ 留白验算 $\rightarrow$ 费曼反问”四步脚手架，同题多步提示共享会话 ID 不重复扣减每日配额；
   * 设备屏幕全局遵循**零技术术语红线**，所有底层异常与网络错误均查表映射为温和、可操作的中文提示。
4. **参数化与模型解耦**：
   * 用户档案中持久化基础学段（`edu_stage`）与入学年份（`enrollment_year`），端云双方按统一日历规则实时派生当前学段标签（`grade_anchor`）；
   * 服务端所有大模型（文本/视觉）、ASR 与 TTS 接口全部通过 `config.yaml` 配置热切换，严禁代码硬编码特定厂商或模型名称。

## 2. 全套工程契约文档地图（`00 ~ 07`）

开发与联调过程中，向 Coding Agent 投喂上下文时必须严格按照 `06-模块化验收标准与联调排坑指南.md` 中的路由表按需投喂，禁止一次性全量投喂：

* **`00-开发总纲.md`**：全局架构宪章、设计原则与文档目录导航（本文档）。
* **`01-硬件物料清单、接线拓扑与物理装配契约.md`**：BOM 选型、全局引脚零冲突矩阵、Strapping 启动电平安全核验、电源保护拓扑与外壳声学/遮光物理装配约束。
* **`02-硬件抽象层与底层驱动契约.md`**：PlatformIO 构建参数、I2C 互斥与 PSRAM 分配边界、六大 HAL 驱动容错规范、FreeRTOS 双核任务划分与跨核队列规范、14 条底层防线清单及全套 `hal_interfaces.h` 接口签名。
* **`03-竖屏界面布局与交互规范.md`**：`320×480` 三区屏幕骨架、三层浮层抢占优先级、页面级摇杆手势仲裁表、统一中文错误码映射表及 13 个核心页面 ASCII 线框。
* **`04-无线网络OTA与本地存储契约.md`**：异步 Wi-Fi 扫描、低磨损 NVS 时钟检查点、TF 卡全目录树与原子写入协议、全量 JSON Schema、`cards.enc` 局部 CTR 解密算法、TTS 磁盘缓存 LRU、业务请求封装与防变砖 OTA 规范。
* **`05-云端接口与AI推理引擎契约.md`**：树莓派 FastAPI 网关目录结构、双向 AES-128-CTR + HMAC-SHA256 安全信封、会话级配额持久化、三级意图分流、防依赖 System Prompt、RESTful API 契约与 Web 管理后台线框。
* **`06-模块化验收标准与联调排坑指南.md`**：按模块划分的精准上下文投喂路由表、原子化 Pass/Fail 验收清单及高频软硬件排坑手册。
* **`07-纯本地电子书阅读模块契约.md`**：纯本地 UTF-8 `.txt` 流式分页内核、`.toc` 章节索引、跨午夜宵禁/时长护栏及树莓派纯本地电子书清洗工坊规范。
* **`verify/`**：端云安全信封的可执行验证脚本 `verify_envelope.py` 与配套向量说明（`05` 第 3.4 节向量组的落地校验入口）。
