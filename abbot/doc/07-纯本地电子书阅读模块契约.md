# 07-纯本地电子书阅读模块契约

## 1. 模块定位与架构红线

* **100% 纯本地沉浸式阅读器**：电子书模块完全基于 TF 卡本地存储与 `3.5 寸 320×480` 竖屏渲染，**零网络请求、零云端大模型依赖、零 API Token 消耗**。
* **语音功能彻底剥离**：为防止看书换手握姿时误触唤醒麦克风并保持模块极简，进入阅读模块（`PAGE_BOOKSHELF` / `PAGE_READER` / `PAGE_BOOK_MENU` / `PAGE_BOOK_TOC` / `PAGE_BOOK_JUMP` / `PAGE_BOOK_LOCKED`）后**全局屏蔽摇杆长按录音浮层（`OVERLAY_RECORDING`）**，摇杆仅承担翻页、调亮度、跳章与返回操作。
* **单进度书签原则（奥卡姆剃刀）**：每本书在 `/records/bookmarks.json` 中仅维护**唯一最新自动阅读进度**（即翻页停顿即自动保存、下次打开秒回原位），不维护复杂的多书签列表，彻底简化交互与存储结构。
* **格式边界（单向清洗）与存储隔离**：
  * **ESP32-S3 固件端**：只解析标准 **`UTF-8` 编码的纯文本 `.txt`** 与轻量章节偏移索引 **`.toc`**，严禁在单片机内引入 `.epub` / `.pdf` / `GBK` 解码库；所有文件读取与保存必须通过 `hal_interfaces.h` 中的 `hal_storage_get_file_size()`、`hal_storage_read_range()`、`hal_storage_read_text()`、`hal_storage_atomic_write_text()` 与 `hal_storage_list_files()` 执行。
  * **树莓派服务端**：提供纯 Python 本地格式清洗工具（`app/book_cleaner.py`，不调用任何 AI 模型），将常见电子书格式一键剥离样式转换为标准 `UTF-8 .txt` + `.toc` 并推送至同步队列或打包下载。

## 2. TF 卡存储格式与防沉迷配置契约

### 2.1 目录与文件规范

```text
/sdcard/
├── books/                          # 电子书仓库目录（支持电脑直接拷贝或后台推送）
│   ├── shiji_01.txt                # 标准化 UTF-8 正文文件
│   ├── shiji_01.toc                # 配套章节字节偏移索引（可选，无则自动隐藏目录入口）
│   └── ...
└── records/
    └── bookmarks.json              # 全局自动阅读进度与每日阅读时长统计（原子写入保护）
```

### 2.2 章节索引文件（`.toc`）格式、分隔符防冲突与越界容错

纯文本行结构，每行格式为 `章节标题|起始字节偏移量`（由树莓派清洗器自动生成，若用户直接拷入裸 `.txt` 无 `.toc` 文件，固件兼容正常阅读并在快捷菜单中隐藏 `[ 章节目录跳转 ]` 项）：

```text
第一回 甄士隐梦幻识通灵|0
第二回 贾夫人仙逝扬州城|14820
第三回 贾雨村夤缘复旧职|29640
```

* **标题含 `|` 分隔符防冲突规则**：固件端解析每一行时，**按行内最后一个 `|`（`strrchr(line, '|')`）切分**，右侧解析为十进制无符号整数偏移量，左侧全部视为章节标题（若清洗器曾将标题内 `|` 转为全角 `｜`，固件渲染列表时还原显示为 `|`）。
* **无分隔符与越界容错红线**：流式加载 `.toc` 文件时，逐行检查是否存在 `|` 分隔符；若某行完全不含 `|`、章节标题为空、右侧偏移量非合法十进制整数，或 **`byte_offset >= txt_file_size`**，**直接丢弃该异常条目**（对应 `ERR_TOC_INVALID` 静默忽略），严禁将非法或越界值传入偏移定位逻辑引发异常。

### 2.3 阅读进度文件（`/records/bookmarks.json`）与写满保护

```json
{
  "schema_version": 1,
  "daily_date": "2026-11-23",
  "daily_used_sec": 1320,
  "books": {
    "shiji_01.txt": {
      "byte_offset": 15420,
      "total_bytes": 482900,
      "percent": 3.2,
      "last_read_ts": 1795412000
    }
  }
}
```

* **磁盘写满保护红线**：调用 `hal_storage_atomic_write_text()` 更新 `bookmarks.json` 时，若因 TF 卡剩余空间不足返回失败，底层自动删除残缺临时文件并**保留原有 `bookmarks.json` 绝不覆盖**，界面弹出轻量 Toast 提示 `ERR_DISK_FULL`（“存储卡空间已满，请清理部分旧缓存后再试。”）。
* **进度百分比实时重算规则**：`bookmarks.json` 中的 `percent` 字段仅为导出快照参考；固件每次打开书籍、进入书架列表或翻页渲染页脚进度时，**严禁直接信任 JSON 中的 `percent` 值**，必须实时按 `(float)current_byte_offset * 100.0f / total_bytes` 重新计算并钳位在 `0.0% ~ 100.0%` 区间显示（当 `total_bytes == 0` 时显示 `0.0%`）。
* 落地细节（字段形状、`.bak` 自愈、保存时机、附录 A.1 ~ A.3）见文末**附录 A**。

### 2.4 防沉迷护栏配置与跨午夜时段算法（复用 `/config/profile.json`）

在全局配置文件 `/config/profile.json` 中读取以下两个配置项（无配置时采用默认值）：

1. **`curfew_window`: `["22:00", "06:30"]`（宵禁时段锁定）**：
   * 仅锁闭 `PAGE_BOOKSHELF` 课外书架入口，不影响准点课表提醒弹窗、番茄钟及系统设置页面的正常使用。
   * **跨午夜比较算法**：将当前时间、开始时间（`start_min`）与结束时间（`end_min`）均换算为当日 `00:00` 起的分钟数（`0 ~ 1439`）：
     * 若 `start_min <= end_min`（同日区间，如 `13:00 ~ 14:00`）：当 `now_min >= start_min && now_min < end_min` 时触发锁定；
     * 若 `start_min > end_min`（跨午夜区间，如 `22:00 ~ 06:30`）：当 **`now_min >= start_min || now_min < end_min`** 时触发锁定。
2. **`daily_book_limit_min`: `45`（每日课外阅读时长上限与精确计时暂停）**：
   * 系统日期跨过午夜 `00:00`（`today_str != daily_date`）时，自动将 `daily_used_sec` 清零并更新 `daily_date`。
   * **计时暂停铁律**：仅当屏幕处于点亮活跃状态且前台页面严格为 **`PAGE_READER`（纯阅读正文页）** 且无任何浮层遮挡时每秒累加 `daily_used_sec`；一旦切入 `PAGE_BOOK_MENU` 菜单页、`PAGE_BOOK_TOC` 目录页、`PAGE_BOOK_JUMP` 跳转页、被 `OVERLAY_REMINDER` 提醒弹窗遮挡或进入自动暗屏休眠，**计时器立即暂停累加**，确保每一秒都只统计真实阅读时间。
* 落地细节（配置来源、拦门点、跨午夜判定、未校时不锁、附录 A.4 ~ A.6）见文末**附录 A**。

## 3. 固件端流式分页内核（零内存膨胀算法）

1. **恒定 `< 3KB` 内存占用**：严禁将整本 `.txt` 读入 SRAM 或 PSRAM。打开书籍时调用 `hal_storage_get_file_size()` 获取 `total_bytes`，每次渲染单页时调用 `hal_storage_read_range(path, current_byte_offset, buf, 1024, &bytes_read)` 读取固定 `1024` 字节局部缓冲区进行排版折行。**UI 层不直接调 `hal_storage_*`** —— 一律经 `ui_data_*`（`src/ui/ui_data.c`）走存储任务的请求/应答通道，UI 任务不碰卡、不碰 SPI（doc/02 §4.2）。
2. **UTF-8 全字节序列边界对齐（含 4 字节生僻字/Emoji 防乱码铁律）**：
   * 无论向前翻页、从 `bookmarks.json` 恢复 `byte_offset`，还是按百分比跳转，必须检查当前偏移处字节的 UTF-8 延续字节掩码：
   * 只要当前字节满足 **`(byte & 0xC0) == 0x80`**（即处于 2 字节、3 字节常见汉字或 **4 字节生僻扩展汉字/Emoji** 序列的中间位置），循环向后步进 `1 ~ 3` 字节，直到遇到完整 UTF-8 字符首字节（`0xxxxxxx`、`110xxxxx`、`1110xxxx` 或 `11110xxx`）为止；
   * 渲染时若点阵字库中未收录某 4 字节生僻字或符号，**必须按全角字符宽度渲染占位方框 `□`** 并正常推进字节指针，严禁死循环或吞字。
3. **单页精确消耗字节记录（`page_bytes_consumed`）**：
   * 渲染器逐行计算中文点阵字符宽度（一行最多 `38` 个半角单位 = `304px`，**全角汉字算 `2` 单位**，即每行最多 `19` 个全角字；遇 `\n` 强制换行；**一屏最多 `14` 行**），实时累计本页实际吞吐的准确字节数 `page_bytes_consumed`；
   * **读缓冲恒为 `1024` 字节**：单页最多 `14 × 19 = 266` 个全角字 = `798` 字节，必小于读缓冲 —— **一页只读一次卡**，折行只在字符边界上发生，**多字节字符绝不切坏**；
   * **向后翻页**：`next_offset = current_offset + page_bytes_consumed`（若 `next_offset >= total_bytes` 则停留在最后一页并提示“已至全书末尾”）；
   * **向前翻页（页网格是全局的，局部窗口反推不出来）**：页边界由「从文件开头逐行排版、每 `14` 行换一页」决定，因此**一个局部窗口无法还原上一页的起点** —— 窗口起点一旦落在行中间，重排出来的行/页边界就与全局不一致（实测会把上一页算偏几个字，甚至落在字符中间）。
     固件因此采用**同规则重扫**：用与正向排版**完全相同**的折行规则从文件头逐块重扫，取最后一个 `< current_offset` 的页起点（扫到 `offset + 1 页` 即可停）；阅读器另在内存里保留**已翻过的页起点栈**，往回翻直接出栈 —— 零读卡、零偏移误差。
4. **无 `.toc` 时的百分比跳转算法（含 100% 末页边界保护）**：
   * 当用户选定目标百分比 `target_pct`（`0 ~ 100`）时：
     * 若 `total_bytes == 0`，偏移量为 `0`；
     * 若 `target_pct >= 100`，先取 `raw_offset = (total_bytes > 256) ? (total_bytes - 256) : 0`，避免直接落到 `EOF` 文件末尾出现白屏；
     * 否则计算 `raw_offset = (uint64_t)total_bytes * target_pct / 100`；
   * 随后调用上述 **UTF-8 首字节边界对齐函数** 向后对齐至最近完整字符起点，立即刷新正文并保存进度。
5. **静默书签落盘**：每次连续翻页停顿超过 `2 秒` 或退出阅读页时，通过 `hal_storage_atomic_write_text()` 更新 `/records/bookmarks.json`。

## 5. 树莓派服务端扩展：纯本地电子书清洗工坊

在树莓派 Web 控制台（`05-云端接口与AI推理引擎契约.md` 第 6 节）的「内容工坊」中提供纯本地电子书清洗子模块（后端对应 `app/book_cleaner.py`，**零 AI API 调用**）：

* **后端处理流水线（纯 Python 库，无大模型开销）**：
  1. `.epub` 使用内置 `zipfile` + `xml.etree` 提取 XHTML 正文文本；`.pdf` 使用 `pypdf` 抽取纯文本；`.docx` 使用 `python-docx` 提取段落；其他编码 `.txt` 自动探测编码并转为标准 `UTF-8`；
  2. 正则清洗多余连续空行、残余 HTML 标签与不可见控制符，统一换行符为 `\n`；
  3. 扫描匹配 `^\s*(第[零一二三四五六七八九十百千万0-9]+[章节回卷篇].*)$`，精确计算每章在输出 `UTF-8` `.txt` 中的字节偏移量，生成同名 `.toc` 文件存入 `storage/books/`，供设备心跳同步或手动拷卡。

## 6. 增量验收标准（Pass/Fail）

* [ ] **大容量零卡顿**：向 TF 卡 `/books/` 放入一本 `5MB` 以上的 UTF-8 小说，点开秒开无延迟，串口打印剩余 SRAM 与 PSRAM 无明显下降。
* [ ] **UTF-8 全字节边界无乱码**：包含 3 字节常见汉字与 4 字节生僻扩展汉字的文本，连续向后翻页 30 页、再向前连续回翻 30 页，每一页首尾字符均完整显示（未收录生僻字显示 `□`），无任何乱码或吞字现象。

## 附录 A. 阅读进度与防沉迷护栏的落地实现（固件）

> 对应契约：本文 §2.3（阅读进度）/ §2.4（防沉迷护栏）。
> 本附录记录**固件侧实际怎么落地**，供联调与验收核对；
> 条款本身仍以 §2.3 / §2.4 为准。

### A.1 落盘格式（`/records/bookmarks.json`）

```json
{
  "schema_version": 1,
  "daily_date": "2026-11-25",
  "daily_used_sec": 1320,
  "books": {
    "shiji_01.txt": {
      "byte_offset": 15420,
      "total_bytes": 482900,
      "percent": 3,
      "last_read_ts": 1795412000
    }
  }
}
```

* **当日阅读时长就放在这份文件里**（`daily_date` + `daily_used_sec`）——
  TF 卡脚手架里没有独立的 `reading.json`，因此不另立文件。
* `percent` 只是**导出快照**；界面显示一律实时重算：实现用整数百分比
  `offset * 100 / total_bytes`，钳位 0~100，`total_bytes == 0` 显示 0%。
* 每本书**只保留一条**进度（唯一最新进度）。

### A.2 原子写与 `.bak` 自愈

* 写入：`ui_data_write_text("/records/bookmarks.json", …)` → 存储任务请求/应答 →
  `hal_storage_atomic_write_text()` 的四步原子替换（`.tmp` → flush → 校验长度 →
  旧文件改名为 `.bak` → `.tmp` 改名）。UI 任务全程不碰 SPI（doc/02 §4.2）。
* 读取：先读正式文件；若**结构不合法或被截断**，回退读
  `/records/bookmarks.json.bak`；主文件与备份都不可用时当作「没有进度」，不编造。
  选择逻辑在纯函数 `ui_book_pick_source()`，主机侧可测。

### A.3 进度显示与保存时机

* 书架列表每本书右侧显示**实时**进度百分比；没有进度显示「未读」。
  书架顶部状态栏显示「今日剩 N 分」（未设上限时显示「今日不限」）。
* 阅读页状态栏显示实时百分比（`已读 N%`，有目录时为 `章节名 · N%`）。
* 保存时机：**每次翻页后**与**退出阅读页时**（长按退回书架）各保存一次。
* 再次打开同一本书：从 `bookmarks.json` 恢复 `byte_offset`，
  并按 doc/07 §3.2 对齐到 UTF-8 字符首字节后再渲染。

### A.4 护栏判定

* 配置来源：`/config/profile.json` 的 `curfew_window`（默认 `["22:00","06:30"]`）与
  `daily_book_limit_min`（默认 `45`）；读不到就用默认值。
* **拦门点**：在书架上短按选中某本书时判定 —— 宵禁时段或今日已读时长已达上限，
  则**不进入阅读**，并切到宵禁提示页给出温和中文提示：
  「现在是阅读休息时段 / 明早再来读书吧」或「今天的课外阅读时间用完了 / 明天再来读书吧」。
  提示文案不出现任何技术术语。
* 跨午夜判定：`start <= end` 用 `now >= start && now < end`；
  `start > end` 用 `now >= start || now < end`。
* 设备未校时（时间不可信）时**不锁** —— 宁可少锁，也不要因为没校时而误锁阅读。
* 每日上限：本地日期跨过午夜（`daily_date` 与今天不同）即清零 `daily_used_sec`。

### A.5 精确计时（暂停铁律）

`daily_used_sec` 只在下列条件**同时**满足时按秒累加：

1. 前台页面严格是 `PAGE_READER`；
2. 没有任何浮层遮挡（提醒弹窗 / 录音浮层 / 提示条都算）；
3. 屏幕点亮（背光档位 > 0）。

其余情况（阅读菜单 / 目录 / 跳转页 / 息屏 / 休眠）一律暂停；
单次间隔超过 2 秒视为停顿，不补计。
