# 03-竖屏界面布局与交互规范

## 一、 视觉基线与色彩系统
* **屏幕物理参数**：`3.5 寸` 竖屏，逻辑分辨率 **`320 × 480 px`**（坐标系左上角 `(0,0)`，右下角 `(319,479)`）。
* **护眼柔和配色（RGB565）**：
  * 全局背景色：`#F4F6F8`（柔和浅灰白，杜绝纯白刺眼）
  * 卡片容器底色：`#FFFFFF`（纯白描边卡片）
  * 主正文文字色：`#1E293B`（深石板灰，高对比清晰）
  * 次要提示文字色：`#64748B`
  * 主强调高亮色：`#2563EB`（沉稳科技蓝，用于当前选中焦点反白/边框）
  * 警告/低电色：`#DC2626`
* **顶部状态栏刷新约束**：仅每 `1 秒`（时钟走时）或电量/Wi-Fi 状态变化时局部重绘 `y = 0 ~ 24` 区域，避免整屏刷新闪烁。

## 三、 全局浮层优先级仲裁与状态机边界

### 3.1 三层全局浮层抢占优先级（高 $\rightarrow$ 低）
1. **`OVERLAY_REMINDER`（准点课表/天气提醒弹窗 — 最高优先级）**：
   * 可随时打断任何当前页面及正在播放/录制的音频。
   * **打断与保护恢复铁律**：若录音期间触发提醒，若已录制有效时长 `>= 1.0 秒` 且 `/outbox/` 未满（`< 10 条`），固件自动将当前录音（及拍题定格图，若有）保存为待问任务写入 `/outbox/queue.json` 并附带轻量提示“录音已自动存入待问队列”，随后立即释放 PSRAM 音频缓冲区并弹出提醒卡片；若不足 `1.0 秒` 或队列已满则直接丢弃。用户在弹窗上**短按摇杆关闭提醒**（长按忽略）后，若此前打断的是 `PAGE_READER` 阅读页，必须精准恢复打断前的字节阅读偏移量并继续阅读计时。
2. **`OVERLAY_RECORDING`（语音录音浮层 — 中优先级）**：
   * **进入方式**：由**页面操作菜单**的语音项进入（首页「语音提问」、解析页「口述你的思路」、卡片页「语音追问这题」），**不再由长按呼出** —— 长按已全局唯一化为「退出」（见第 3.2 节），语音若再占用长按就会重新引入同键多义。进入后立即开始录制，顶部动态显示实时音量波形条与倒计时（最长 `10 秒`）；
   * **短按结束并提交**：浮层内短按中心键即结束录制并把音频送云端；**长按等同于取消**（退出录音态，不联网、不入队 `/outbox/`）；
   * **上推取消状态（`STATE_RECORD_CANCEL`）**：录音进行中向上推动摇杆即切入 `STATE_RECORD_CANCEL`，浮层提示“上推取消录音”，松开按键直接释放内存，不联网、不入队 `/outbox/`。
3. **`OVERLAY_TOAST`（轻量状态提示条 — 最低优先级）**：
   * 底部悬浮 `2 秒` 提示条，**严禁覆盖**提醒弹窗与录音浮层。

### 3.2 六手势宪法（消除同键多义冲突）

真机只有**一个**中心按键与**四向**摇杆轴，因此全局只保留 **6 个手势**，每个手势**在任何页面只有 1 个含义**。

| 手势 | 全局唯一含义 | 落地细节 |
| :--- | :--- | :--- |
| **上推 (`UP`)** | 导航：向上 | 列表光标上移一项；长文本向上滚动；`READER` 背光 `+1` 档；`JUMP` 进度 `+10%` |
| **下推 (`DOWN`)** | 导航：向下 | 列表光标下移一项；长文本向下滚动；`READER` 背光 `-1` 档；`JUMP` 进度 `-10%` |
| **左推 (`LEFT`)** | 导航：向左 / 往回 | `READER` 翻到**上一页**；`TOC` 目录往回翻；`JUMP` 进度 `-1%`；卡片上一张；滑块减 |
| **右推 (`RIGHT`)** | 导航：向右 / 往前 | `READER` 翻到**下一页**；`TOC` 目录往前翻；`JUMP` 进度 `+1%`；卡片下一张；滑块加 |
| **短按 (`CLICK`)** | **确定**：确认当前选中项 / 关闭当前浮层 | 进入选中页面；确认菜单项；拍照；翻面；关闭提醒弹窗 |
| **长按 (`LONG`)** | **退出**：退回上一级 / 关闭当前浮层 | 按住 `>= 600ms` 后**松开**才生效；退回书架；取消录音 |

**废除双击**：真机只有一个中心键，双击依赖「两次按下的时序判定」，而这个判定与长按阈值在同一条时间轴上互相挤压 —— 想长按时系统正在等第二次按下，想双击时第一次按下可能已被判成长按。既然「短按确定 / 长按退出」已经覆盖全部导航需求，双击不产生任何独占能力，只带来误判。故固件**不实现双击事件**，原「双击＝返回上一级」统一并入**长按＝退出**。

**语音不再占用任何手势**：语音提问一律从**页面操作菜单**进入（首页「语音提问」、解析页「口述你的思路」、卡片页「语音追问这题」）。这样长按在全局只剩「退出」一个含义，彻底消除同键多义。

**长按生效时机**：长按的**释放瞬间**才生效（按住 `>= 600ms` 后松开），避免误触即退。阈值由 HAL 层 `02` 文档第 3.4 节**唯一裁定**，UI 层严禁自行计时判定。

**浮层优先级**（不随本次重写改变）：
1. `OVERLAY_REMINDER`（提醒弹窗）：**短按**关闭并恢复原页；**长按**忽略。
2. `OVERLAY_RECORDING`（录音浮层）：**短按**结束并提交；**上推**取消（`STATE_RECORD_CANCEL`）；**长按**等同于取消。
3. `OVERLAY_TOAST`：不响应手势，2 秒自动消失。

**各页方向键的额外语义**（仅方向键可多义，短按/长按不可）：

| 页面 | 上推 / 下推 | 左推 / 右推 | 短按 | 长按 |
| :--- | :--- | :--- | :--- | :--- |
| `PAGE_HOME` | 菜单光标移动 | — | 进入选中项 | 复位到首项 |
| `PAGE_CAMERA` | — | — | 拍照 | 退出返回 |

## 五、 13 个核心页面状态与 ASCII 布局线框

### 0. 首次开机引导流（`PAGE_OOBE`）

> **2026-11-25 修订**：引导流取消「敲 6 位配对码」这一步。
> 设备联网后自动向学习助手报到（doc/04 §1.2），本页只展示**接入进度**。

* **触发条件**：开机检测到 NVS 中无已保存 Wi-Fi 且 `paired == false`（且 `profile.json` 中 `skip_oobe_offline == false`）。
* **流程**：`本页（接入进度）` $\rightarrow$ `连接 Wi-Fi（复用 PAGE_WIFI_SCAN）` $\rightarrow$ `选学段与入学年份` $\rightarrow$ 进入 `PAGE_HOME`。
  **配对码录入不在引导流里** —— 6 位码降级为兜底，只在 `PAGE_SETTINGS -> 设备配对绑定` 里。
* **接入进度由网络任务驱动**：网络任务（Core 0）完成自动登记后投 `ui_command_t.kind=5`
  （`UI_PAIR_STATE_NONE/PENDING/READY/FAILED`），UI 任务（Core 1）据此改写进度文案。
  **UI 不自己计时、不发网络请求。**
* **接入成功自动进首页**：`UI_PAIR_STATE_READY` 时若当前页是 `PAGE_OOBE`，自动跳 `PAGE_HOME`
  —— 设备侧零输入，家长不需要按任何键。
* 页面始终提供 **`[ 先离线体验 ]`**（写 `skip_oobe_offline = true`，后续可在系统设置里随时接入）。

### 6. 电子书架（`PAGE_BOOKSHELF`）& 7. 沉浸阅读页（`PAGE_READER`）

### 8. 番茄专注时钟页（`PAGE_POMODORO`）
* **时长可设**：默认 `25 分钟`；在 `PAGE_SETTINGS` 第 7 项「专注时长」里用左右键按 `5 分钟` 一档调整（范围 `5 ~ 60 分钟`），调整结果**原子写入 TF 卡** `/config/settings.json`（`.tmp → flush → 校验 → .bak → 重命名`，见 `04` 文档 §2.3），**断电后仍在**（写的是「时长设置值」，不是计时状态）。
* **计时状态仅驻留内存**：当前这一轮的剩余时间不落盘；倒计时按**毫秒**推进（不用秒级累加），长跑不漂移。
* **到点出声**：设备端合成提示音（`hal_audio_request_tone` → 音频任务真正出声，**不阻塞 UI 任务**），并进入「已完成」态；已完成后再按一次短按 = 重新开始一轮。
* **手势**：短按 = 暂停 / 继续；长按 `600ms` 松开 = 结束并退出。

### 10. 系统设置主菜单（`PAGE_SETTINGS`）
包含 8 项设置入口：
1. **无线网络配置**（进入 `PAGE_WIFI_SCAN`）
2. **设备配对绑定**（进入 `PAGE_KEYBOARD` 输入 6 位数字配对码）—— **兜底路径**，
   正常情况下设备开机已自动登记（doc/04 §1.2），不需要家长操作
3. **播报音量调节**（1~5 档实时切换并播放测试音）
4. **屏幕背光亮度**（1~5 档实时切换）
5. **离线手动校时**（断网无 NTP 时手动调整当前日期与小时分钟，保存后立即写入时钟检查点）
6. **固件版本与 OTA 升级**（显示当前版本号、设备 ID，短按检查并执行 OTA 升级）
7. **专注时长**（番茄钟时长，默认 `25 分钟`）：光标停在本项时**左右键**按 `5 分钟` 一档减 / 加（范围 `5 ~ 60 分钟`），右侧显示当前分钟数；调整后立即**原子写入 TF 卡** `/config/settings.json`，断电后仍在。
8. **所在城市**（右侧显示当前城市中文名，未设置时显示「未设置」）：短按进入 `PAGE_CITY` 选城市。
   选完**立即生效**：城市原子写入 `/config/settings.json`（离线兜底），
   同时写进 net 层缓存、随下一次心跳（`/api/v1/sync/bootstrap` 的加密请求明文里的 `city` 字段）上报给服务端，
   并立刻补发一次心跳；服务端 ≤30 秒后抓取该城市天气（doc/05 §5.2）。
   → **改城市不会弄丢「专注时长」**（两者写在同一张 `settings.json` 里，读-改-写）。

### 10.1 天气显示（首页状态行）

* 首页左上角显示**服务端下发的实况**：`{天气短语} {温度}℃`（如 `晴 22℃`）。
* 三种状态，**都不报错、不阻塞**：
  | 状态 | 屏上显示 | 触发条件 |
  | :--- | :--- | :--- |
  | 在线 | `{短语} {N}℃` | 心跳应答里 `weather` 非空对象 |
  | 空态 | `暂时拿不到天气` | 服务端返回 `weather: {}`（城市刚改完还没生效、或抓取失败） |
  | 离线兜底 | `{短语} {N}℃（缓存）` | 当前离线，用 TF 卡 `/cache/weather.json` 里上次读数 |
* 缓存由固件在每次拿到在线读数时写入（原子写），**离线时也不会开天窗**。

### 11. Wi-Fi 热点自扫描列表（`PAGE_WIFI_SCAN`）
* 信号强度分级映射：`RSSI > -60dBm` 显示 `[信号强]`，`-60dBm ~ -75dBm` 显示 `[信号中]`，`< -75dBm` 显示 `[信号弱]`。
* **列表是真扫描结果**（不是写死的样例）：进页时 UI 向网络任务提交一次扫描请求，
  网络任务在 Core 0 异步扫描并把结果缓存回来，UI 心跳轮询取回。
  同名 SSID 合并（保留信号最强的那条）；已保存的网络前面带 `★`；
  加密网络标 `[加密]`，开放网络标 `[开放]`；隐藏网络显示 `(隐藏网络)`。
* 顶部状态行给出阶段反馈：扫描中 / 连接中 / 已连上 / 没连上 / 附近没搜到网络。
* 短按行为：
  * 选中**加密**网络 → 进 `PAGE_KEYBOARD` 输密码 → 确认后回来发起连接；
  * 选中**开放**网络 → 直接发起连接；
  * 选中最后一行 `[ 重新扫描周边热点 ]` → 重新扫一次。
* 连接失败（密码不对或 12 秒超时）→ 状态行提示「无线网络连接失败，请核对密码后重试」，
  光标停在原网络上，**再短按一次即可重试**（最多 3 次，之后提示核对密码或换网络）。
* 底部提示语：`上下选择 | 短按连接 | 长按退出`。

* **为什么要候选列表**：让用户打拼音还得自己判对错，孩子根本做不到。

  5. 返回设置页，右侧城市名刷新。

### 14. 固件侧天气链路口径（与 doc/05 §5.2 对应）

| 环节 | 固件侧约定 |
| :--- | :--- |
| 城市上报 | 心跳 `POST /api/v1/sync/bootstrap` 的**加密请求明文**里带 `"city":"Shanghai"`（裸地名，**不带 `v` 前缀、不带经纬度**）；也可在首次登记 `POST /api/v1/device/register`（明文请求）里带 |
| 空态识别 | 服务端 `weather` 为**空对象 `{}`** 或缺字段 → 显示「暂时拿不到天气」，**不当作错误** |
| 服务端不回传城市 | 服务端**不回传**城市（bootstrap 应答形状不动）→ 固件自己把城市落一份到 TF 卡做离线兜底 |
| 生效延迟 | 服务端 ≤30 秒才生效 → 这期间 `weather` 是空对象 → 固件显示空态（**不是**缓存，也不是错误） |
| 缓存城市不符 | 服务端缓存城市与设备城市不符时也返回 `{}` → 固件照空态显示，**不当故障重试** |
| 离线兜底 | 固件把最近一次在线读数写入 TF 卡 `/cache/weather.json`，离线时显示 `{短语} {N}℃（缓存）` |
| 隐私 | 城市名**只用于天气**，不进任何日志；密码同理不入日志 |
