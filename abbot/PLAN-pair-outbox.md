## 拍板依据

- **配对去认领层**（ALIGN-NOTES §9.20 / 提交 edd2469）：不需要家长认领、不需要家长敲 6 位码。
  设备开机联网 → 自动向网关登记 → 网关签发密钥 → 入网。全程无码、无弹窗。
  网页端只是"能看到这台设备"，看都不用点。
  密钥为什么仍要有：①请求 HMAC 签名 ②学科包按设备加密 ③配额按设备记账；
  且 doc/04 §1.2 定「零预烧录」，密钥不能硬编码在固件里。
- **离线必做**（doc/04 §1.3）：电子书阅读、学科刷卡、番茄钟、本地课表断网照常。
  端云功能在断网时进 outbox 排队，联网后补传。

## 本块三件事

### 1. 配对简化：自动登记，无码
- 固件侧：开机后自动向网关登记（用芯片 MAC 派生的 `device_id`，格式 `esp32s3_<mac8>`，已有）。
  网关签发 `device_secret` → 设备存 NVS → 之后所有请求照常签名。
  设备侧**零输入**：不弹码、不进虚拟键盘、不要求家长操作。
- 网关侧（`server/app/`）：新增登记端点，签发密钥并落盘；管理台能看到设备列表与状态。
- 幂等：同一 `device_id` 重复登记 → 返回同一份密钥，不重复签发、不泄漏给他人。
- 密钥**不得回传浏览器**；浏览器只能看到"这台设备已接入"。
- 现有 `net_pair_with_code()` 与 PAGE_OOBE 虚拟键盘页：改成"自动登记中…"的进度态，
  不再要求家长敲码；旧路径保留为兜底（若网关不支持自动登记）但默认不暴露。

### 2. 离线队列（outbox）
- 索引文件 `/outbox/queue.json`，最多 **10 条**，原子写 + `.bak` 自愈。
- 拍照/语音这类需要云端的请求，断网或未配对时**入队**而不是失败。
- 联网后逐条补传，成功则移除索引条目并删除关联的 JPG/PCM 文件。
- 队列条目要记：类型、创建时间、关联文件路径、重试次数。
- 重试上限与过期策略要定（写进 doc/05 或 doc/04，别只在代码里）。
- 未配对时也允许入队（配对完成后一并补传）。

### 3. 学科包 cards.enc 解密 + 卡片学习页
- 固件端解 `cards.enc`（AES-128-CTR，密钥 = `device_secret[0:16]`）。
- 学科卡学习页：正面题干 → 短按翻面看答案 → 长按退出。
- 解密失败给温和中文提示（不暴露 AES/密钥等术语）。

## 硬约束（不变）

- 固件只由 GitHub Actions 编译；本机禁 PlatformIO，只允许 gcc 主机侧测试。
- 交互宪法：四向导航 + 短按确定 + 长按 600ms 松开退出；长按阈值只由 HAL 裁定；
  保留摇杆输入；语音只能从菜单进入，录音中短按结束并提交、上推取消。
- UI 只经 `hal_storage_*` 读卡，按 doc/02 §4.2 走存储任务请求/应答；UI 任务不碰 SPI。
- 错误文案不得出现 AES/HTTP/signature/Token/Python/Traceback 等技术术语。
- abbot 外网入口保持明文 HTTP，不做 HTTPS。
- 设备密钥/HMAC/AES 真实调用留在设备与服务端，密钥不回传浏览器。
- 只改 abbot 范围内的文件；`.env`、密钥、缓存不入库。
- **小步提交**：每完成一块就同步 + 提交 + 推，别全攒到最后。
