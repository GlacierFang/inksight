# 小景（CUSTOM_XIAOJING）

> 每天画一小片世界，跟着此刻的光线换色。 <!-- project: path:/home/open/.openclaw/workspace -->

## 是什么

四色墨水屏上的一个纯图模式。屏上只有一张画，没有文字。

- **风格固定**：赛璐璐平涂 + 波普网点/放射线 + 四色墨水 + 人在场景里占比很小。
- **场景自由**：地形、角色、姿态、构图全部由 AI 每次重新发明。
- **时刻由程序定**：按真实日出日落算出晨/昼/暮/夜，写进提示词，并在本地按该时段的配方调一次色。
- **跨时段即换图**：一天里晨→昼→暮→夜，屏上的光走完一整轮。

## 为什么这么切分（2026-11-01 冰河大人定的）

冰河大人两次纠正了最初的方向：

1. 「形象和位置都固定下来了，那就没意思了」—— 手画占位稿把角色和站位写死了。
2. 「谁说背景是固定的呢？」—— 提示词里写死场景描述，等于我在替画师作画。

所以：**只有风格规则是固定的，场景/角色/构图一个字都不写死**。
提示词里只给一个名词线索（今天路过的是「一座木桥」），剩下的画师自己决定。

时刻也不能交给模型：实测模型对「the middle of the night」的理解会飘，
会把夜画成落日（第一版试出来的两张「夜」都是黄昏）。
所以时刻由程序按真实太阳位置算，再在本地调色兜一层。

## 关键实现点

- **时段分档**（`_phase_from_sun`）：日出前 40 分钟前=夜；日出后 100 分钟内=晨；
  日落前 100 分钟前=昼；日落后 60 分钟内=暮；其余=夜。
  取不到日出日落数据时退回粗分档（`_phase_from_clock`）。
- **调色只决定四色比重，不做四色归色** —— 归色是渲染器的 Atkinson 抖动干的活。
  夜色把中低调压到接近墨黑、只留高光（月亮）。
- **画心 400×264**：400×300 屏上状态栏 36px + 图 264px + 无页脚 = 正好占满。
  屏上显示尺寸必须与模式 JSON 里 image 块的 width/height 一致，否则渲染器会二次缩放。
- **出图失败退成沿用旧图**，不让屏空着；锁防重复扣费（`generate.lock`）。
- **历史日只读不补生成**：那天没生成过就是没生成过。
