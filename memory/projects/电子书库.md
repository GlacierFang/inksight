### Chunk 队列处理系统

| 组件 | 说明 |
|------|------|
| 队列文件 | `/home/open/.openclaw/workspace/memory/library/chunk-queue.json` |
| 进度目录 | `/home/open/.openclaw/workspace/memory/library/chunk-progress/` |
| 处理脚本 | `/home/open/.openclaw/workspace/skills/library/chunk_worker.py` |
| 启动脚本 | `/home/open/.openclaw/workspace/skills/library/run_chunk_worker.sh` |
| Cron 配置 | 系统 cron，每分钟执行 |

**优势：**
- 后台队列处理，不阻塞页面
- 进度实时追踪
- 中断后可恢复
- 不消耗 MiniMax API（系统 cron 直接执行）

### 暂停/恢复功能

| 接口 | 方法 | 说明 |
|------|------|------|
| `/library/api/chunk/pause` | POST | 暂停处理 |
| `/library/api/chunk/resume` | POST | 恢复处理 |
| `/library/api/chunk/pause-status` | GET | 查看暂停状态 |

**使用方式：**
- 书籍详情页有「⏸️ 暂停」按钮
- 暂停后按钮变为「▶️ 恢复」
- 暂停状态持久化（文件标志）

**当前状态：** 已暂停（等待 MiniMax 请求量恢复）
