# 个人知识管理（visit-knowledge）

## 项目概述
用户上传照片 → AI打标签 → 确认标签 → 加入待生成队列 → 用户说「开始生成」→ 按标签分组搜索背景资料 → 生成飞书文档，同时生成本地HTML备份

## 触发词
- 「开始生成」
- 「查看待生成列表」
- 「删除待生成照片」
- 「查看本地备份」

## 本地备份功能详情

### 访问
- 地址：`http://192.168.31.194/visit/`
- 服务：Flask 端口 18793，systemd 服务 `visit-knowledge-viewer.service`

### 文档结构
每个标签生成一个 HTML 文件，包含：
- 标题、标签、参观时间
- 照片缩略图（点击查看大图）
- 背景资料
- 飞书原文档链接

### 文档生成
- 调用 `viewer/doc_generator.py` 的 `generate_html_doc()` 函数
- 参数：tag, photos_data, background_info, feishu_doc_url
