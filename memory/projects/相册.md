# 相册（gallery）

## 项目概述
OpenClaw 瀑布流相册系统，支持通过飞书/微信上传图片视频，局域网网页浏览。

## 访问地址
- 本地：`http://localhost:18790/gallery`
- 局域网：`http://<设备IP>:18790/gallery`
- Nginx 代理：`http://192.168.31.194/gallery/`（推荐，更快）

## 技术栈
- Python Flask（端口 18790）
- 技能目录：`/home/open/.openclaw/openclaw_safe_storage/.openclaw/workspace/skills/gallery/`（注意：在 openclaw_safe_storage 下）
- 数据库：`/home/open/.openclaw/openclaw_safe_storage/.openclaw/media/gallery.db`（SQLite）
- 媒体目录：`/home/open/.openclaw/openclaw_safe_storage/.openclaw/media/photos/`

## 照片上传流程

```
飞书/微信上传 → inbound/ → organize.py(每5分钟) → AI标签队列
                                              ↓
                     AI tagger(每30分钟) → 添加 ai_tags
                                              ↓
                     organize.py → photos/ (相册)
```

## SQLite 数据库（当前架构）

### 表结构

```sql
photos(id, filepath, date, timestamp, source, media_type, ai_desc, ai_tagged_at, created_at, updated_at)
tags(id, name, category, is_system, created_at, updated_at)
photo_tags(id, photo_id, tag_id, source, created_at)  -- source: 'ai' or 'user'
tag_aliases(id, tag_id, alias, created_at)
```

### 数据现状（2026-03-31）
- 照片：32 张
- 标签：69 个
- 照片文件：70 个（含缩略图）
