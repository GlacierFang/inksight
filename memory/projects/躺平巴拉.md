## 一、项目定位

**名称：** 躺平巴拉

**一句话定位：** 养一只水豚，看它躺平，等它带回诗与冰箱贴。

**核心体验：** 佛系、躺平、无压力。玩家不控制水豚的行为，只准备道具，等它发呆、做梦、或自己溜达出去，回来时带一个惊喜。

**目标用户：** 初中生+高中生（备考间隙的放松）+ 佛系青年 + 博物馆文创爱好者 + 古诗词兴趣用户

**与翰墨时空谱的关系：** 躺平巴拉借鉴翰墨时空谱的诗文数据（109篇）和文物数据（195件），两者是独立产品，无协同绑定。

## 二、核心差异化（对比旅行青蛙）

| 维度 | 旅行青蛙 | 躺平巴拉 |
|------|---------|---------|
| 主角 | 青蛙+动物朋友们 | 水豚（卡皮巴拉）+ 它的朋友们 |
| 主角行动 | 外出旅行（有目的地） | 室内躺平/偶尔外出溜达 |
| 核心等待 | 等它去哪儿、什么时候回 | 等它发呆/做梦/溜达，回来就行 |
| 收集物 | 明信片 | 诗文明信片 **或** 文物冰箱贴（随机一面） |
| 货币 | 三叶草 | 知识泉水 |
| 道具 | 便当/护身符/帐篷 | 诗集/茶叶/温泉包/文房四宝/古地图/幸运草 |
| 时间感 | 分钟级等待 | **小时级（室内）/ 天级（外出）**，突出躺平 |
| 地图 | 日本各都道府县 | **无需地图**，室内场景，外出无追踪 |
| 文化深度 | 无 | 诗文明信片（正面图+反面文），文物冰箱贴（正面图+反面文） |
| 美术风格 | 日系清新 | 中式温暖（水墨+博物馆文创美学） |

## 三、核心玩法循环

```
知识泉水缓慢积累（每日5滴，封顶，不累积）
    ↓
在商店用知识泉水兑换文化道具
    ↓
消耗品放入背包，永久道具点击"使用"放置到对应位置
    ↓
水豚在家 idle 时，每15分钟一档，每档独立判断：
    - 访客是否来（7%/天 ≈ 每档0.075%）
    - 是否触发外出（5%/天 ≈ 每档0.052%，有幸运草15% ≈ 每档0.16%）
    - idle 状态下是否抽中道具触发状态（当日首次抽中后停止）
    ↓
触发：诗文明信片 / 文物冰箱贴 / 梦境明信片
    ↓
收到后 → 弹出模态框查看（正面图片，点击翻面看文字）
    ↓
下次再收到新的，继续弹出模态框
```

**离线时间补偿：**
- 每次打开 App，按离线时长计算有多少个15分钟档位
- 每个档位独立做概率判定，结果一次性应用
- 用户回来时看到的是这段时间推进后的状态（访客是否来过、外出是否触发等）

**翻转说明：**
- 点击后直接展示背面内容，不需要翻转动画
- 没有"双合"概念，每次收到都是独立的一张卡

**外出溜达：**
- 水豚偶尔自己溜达出门，6~24小时后回来，70%/80%概率带东西回来

## 四、主角·水豚

### 角色设定
- 名字：巴拉
- 性格：躺平大师，情绪稳定，慢悠悠
- 视觉：圆润、呆萌、有时发呆、有时打盹、有时泡温泉
- **idle 状态**：默认状态，随机在三个活动间轮换——嚼草根 / 睡觉 / 发呆，每个活动持续几分钟到几十分钟（随机）
- **访客来时**：水豚和访客一起做对应的活动（访客动画单独提供），不触发道具状态
- **tick 系统**：水豚 idle 时每15分钟一档，每档有极低概率触发道具（当日首次抽中后停止）

### 房间布局（5×7 虚拟网格）

```
竖屏 5×7 虚拟网格：

列:  0    1    2    3    4
行:0  [古地图] [古地图] [  ] [  ] [设置]
行:1  [  ]  [  ]  [电脑] [  ]  [收藏箱]
行:2  [书架] [  ]  [  ]  [  ]  [茶几]
行:3  [  ]  [  ]  [水豚]  [  ]  [  ]    ← 水豚活动区
行:4  [  ]  [  ]  [水豚]  [  ]  [  ]    ← 水豚活动区
行:5  [电冰箱] [  ] [书桌]  [  ] [澡盆]
行:6  [  ]  [  ]  [  ]  [  ]  [窗台]
```

| 古地图 | 墙上（行0列1/2） |

### 水豚室内状态

| 状态 | 触发条件 | 时长 | 产出 |
|------|---------|------|------|
| 读书 📖 | 书架有诗集（当日随机抽中） | 5~20分钟 | 无 |
| 泡温泉发呆 🛁 | 澡盆有温泉包（当日随机抽中） | 30~60分钟 | 10%梦境（有温泉包+10%=20%） |
| 喝茶冥想 🍵 | 茶几有茶叶（当日随机抽中） | 1~3小时 | 无 |
| 写毛笔字 ✍️ | 书桌有文房四宝（当日随机抽中） | 1~3小时 | 无 |
| idle 💤 | 无道具 | — | 无 |

**触发规则：**
- 水豚 idle 在家时，每15分钟一档，每档独立判断
- 当日首次抽中道具触发后停止，不再判断
- 访客日不触发任何室内状态
- 外出中不判断状态触发

### 访客系统

**触发概率：** 每自然日 7%

| 访客 | 概率 | 互动方式 |
|------|------|---------|
| 花枝鼠 🐭 | 60% | 一起嚼草根 |
| 蜜袋鼯 🦬 | 30% | 一起睡觉 |
| 豹纹守宫 🦎 | 10% | 一起发呆 |

**访客时长：** 12小时，到时自动消失（用户打开App时检查，超时则清除）

**访客到来时：**
- 访客动物出现在水豚旁边，emoji 展示
- 房间顶部显示「访客日」标签
- 豹纹守宫有30%概率送幸运草（静默，不弹窗）
- 当日泉水从5滴立即翻倍至10滴（封顶同步翻倍）
- 当日暂停使用已放置的道具（不触发室内状态），但不影响购买

**访客离开时：** 12小时到时自动消失，无告别提示，泉水恢复正常（不再翻倍）

### 外出溜达
- 触发：纯随机，幸运草提升外出概率（无幸运草5%/天，有幸运草15%/天）
- 外出时长：6~24小时
- 回来时：无古地图70%概率带东西（30%空手），有古地图80%概率带东西（20%空手）
  - 带东西时：50%诗文明信片 / 50%文物冰箱贴

## 五、收集系统

### 明信片与冰箱贴

每次水豚带回的"惊喜"是**一张卡**，随机为以下形态之一：

| 形态 | 内容 |
|------|------|
| **诗文明信片** | 正面：诗文意境图；反面：诗文原文+作者 |
| **文物冰箱贴** | 正面：文物图样；反面：文物简介+馆藏信息 |
| **梦境明信片** | 泡澡发呆时10%概率触发（有温泉包20%），诗文全文+简短注释，特殊边框 |

### 查看方式
- 水豚带回时 → 弹出模态框，显示名称和类型
- 收藏箱/电冰箱 → 列表弹窗，点击任意卡 → 单卡弹窗（默认正面图片，点击翻面看文字）

## 七、道具体系

### 道具分类与价格

||| 道具 | 类型 | 价格 | 效果 |
|------|------|------|------|------|
| 茶叶 | 消耗品 | 1滴 | 放到茶几，有概率被水豚抽中喝茶，触发后茶叶消失 |
| 温泉包 | 消耗品 | 1滴 | 放到澡盆，有概率被水豚抽中泡澡，触发后温泉包消失，梦境明信片概率额外+10% |
| 诗集 | 永久道具 | 20滴 | 放到书架，有概率被水豚抽中读书，永久存在，商店显示已购 |
| 文房四宝 | 永久道具 | 20滴 | 放到书桌，有概率被水豚抽中练字，永久存在，商店显示已购 |
| 古地图 | 永久道具 | 20滴 | 放置后提升外出带回概率（70%→80%），永久存在，商店显示已购 |
| 幸运草 | 消耗品（7天枯萎） | 2滴 | 放到窗台，点"使用"替换新的，7天枯萎前持续有效 |

### 道具商店规则
- 所有道具购买后先进入背包
- 永久道具：进入背包后点击"使用"放置到对应位置，永久存在
- 消耗品：进入背包后点击"放置"放置到对应位置，被抽中后消失
- 商店分两个 Tab：可购买 / 背包

### 道具放置规则
- **永久道具**：购买后点"使用"放置到对应位置，永久存在
- **消耗品**：购买后放入背包（不立即放置），背包里有才能放置到对应位置
- **幸运草**：点"使用"直接替换窗台上现有的（重置7天计时）

### 触发逻辑
- 无物品 → 不触发任何效果
- 有物品 + 水豚在家 → 随机抽一个道具触发效果，**当日仅触发一次**
- 有物品 + 水豚外出 → 物品不消耗，等回家后以同样随机逻辑触发
- 访客来临时 → 当日道具全部暂停

## 水豚 PNG 帧动画规划（2026-09-24 调研，待开工）

### 调研结论：5 FPS 契合躺平气质，不改

48 张 / 10s = **4.8 FPS**，比 idle 标准还慢一档，符合"水豚节奏"。

| 参考来源 | idle 标准 | 备注 |
|---------|----------|------|
| Pixnote 像素动画指南 | idle **6 FPS** | "casual stroll"；12 FPS 是"刚刚好" |
| sprite-ai.art | idle 呼吸 2-4 帧 ping-pong，400-800ms/帧（1.25-2.5 FPS） | 极慢呼吸感 |
| Divoom 像素动画 | idle 8 FPS | "下移 1-2 像素的呼吸" |
| 旅行青蛙水墨 | ~6-8 FPS（肉眼估算） | 相邻产品 |

### 待拍板的 3 个决策（冰河大人定）

1. **循环方式**：无缝接回（48→1 帧不停顿）—— 躺平美学
2. **状态切换过渡**：无淡入（硬切）—— 符合"逐帧动画"语言；如要温和可加 200ms 渐显（不推荐）
3. **首版范围**：只做 **bathing + 3 idle mood**（grazing/sleeping/daydreaming）= **4 状态 × 48 = 192 张 PNG**
   - reading / drinking / writing 用 emoji 占位
