## 三个页面

### 1. Overview（总览）
- **健康状态条**：🟢系统正常 / ⚫️数据过期 / 🟡运行预警 / 🔴系统异常
- **5 个统计卡**：API 调用（本期）/ 窗口配额 / 本月发布 / 深入分析 / 系统状态
- **🔌 数据源连接状态**：Cron/Sessions/TokenPlan/API日志/历史趋势
- **💾 磁盘空间**：Gallery/Library/工作空间细分
- **发布日历 + 日历详情面板**：点击日期查看当天任务，一键标记"已发布"
- **深入分析**：当前正在分析的书 + 进度条
- **记忆状态**：MEMORY.md 最后修改时间 + 待整理日志
- **今日活动**：24小时柱状timeline
- **快速入口**：各系统链接

### 2. Usage（用量）
- **🔥 Burn Rate**：Token Plan 真实配额（5h窗口 / 本周 / 预计耗尽）
- **📊 用量来源拆分**：按来源（main/cron/wechat/feishu）
- **来源柱图/饼图**（D3.js）：按来源分布
- **近30天柱状图**（D3.js）：每日调用趋势
- **Cron Token 排行**：Top 5 Cron 任务
- **Agent 活跃度**：30天趋势

### 3. Sessions（员工）
- **🧠 上下文占用**：所有 session 的 context 使用率 TOP 10（含类型分布）
- **5 个统计卡**：总会话 / 🟢工作中 / 🔵执行中 / ⚪空闲 / 订阅窗口
- **会话详情列表**：每个会话的 label + 类型标签 + 状态 + 最后活跃时间 + Context Pressure 百分比
- **发布日历**（同 Overview）

## Token Plan 集成（重要）

**MiniMax API 端点：**
```
GET https://www.minimaxi.com/v1/api/openplatform/coding_plan/remains
Authorization: Bearer <API Key>
```

**API Key 存储位置：** `~/.openclaw/agents/main/agent/auth-profiles.json`

**数据说明：**
- M2.7 配额数据**完全可信**（5h窗口 + 本周两个维度）
- speech-hd / image-01 的 interval 与后台「自然日」口径不一致，仅供参考
- 每周一 00:00 UTC+8 重置本周配额
- 5h 窗口每天滚动刷新

**相关 API：**
- `/api/token-plan` — 返回所有模型的原始配额
- `/api/burn-rate` — 基于 M2.7 计算消耗速率和预计耗尽
- `/api/connector-status` — 显示 Token Plan 连接状态
