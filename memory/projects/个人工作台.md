## 三个页面

### 1. Overview（总览）
- **健康状态条**：🟢系统正常 / ⚫️数据过期 / 🟡运行预警 / 🔴系统异常
- **本时段模型调用量 / 本时段剩余调用量**：来自 MiniMax Token Plan（已修正字段映射）
- **本月发布 / 按时率**：自媒体发布统计
- **🔌 数据源连接状态**：Cron / Sessions / API日志 / 历史趋势
- **💾 磁盘空间**：Gallery / Library / 工作空间细分
- **发布日历 + 日历详情面板**：点击日期查看当天任务，一键标记"已发布"
- **🧠 记忆状态**：MEMORY.md 最后修改时间 + 待整理日志
- **今日活动**：24小时柱状timeline
- **快速入口**：各系统链接

### 2. Usage（用量）
- **📦 工作数据**：SSD存储 / 照片数 / 电子书 / 已索引
- **📈 近30天调用趋势**：每日调用次数柱状图（D3.js）
- **📊 用量来源拆分**：按渠道（主会话/定时任务/飞书/微信）以调用次数统计
- **系统状态**：各数据源连接详情

### 3. Sessions（对话）
- **总会话 / 🟢工作中 / 🔵执行中 / ⚪空闲 / 订阅窗口**：会话状态统计
- **订阅窗口**：Token Plan 5h窗口已消耗/总量
- **🧠 上下文占用**：所有 session 的 context 使用率（含类型分布）
- **🤖 Cron 任务调用次数排行**：近7天 Top Cron 任务
- **👥 会话详情列表**：每个会话的 label + 类型标签 + 状态 + 最后活跃时间 + Context Pressure

## Token Plan 字段映射（重要）

**MiniMax API 端点：**
```
GET https://www.minimaxi.com/v1/api/openplatform/coding_plan/remains
Authorization: Bearer <API Key>
```

**API Key 存储位置：** `~/.openclaw/agents/main/agent/auth-profiles.json`

**字段映射（MiniMax API → 内部语义）：**
- `interval_remain`（API返回）= 已消耗量
- `interval_used`（API返回）= 剩余量
- `weekly_remain`（API返回）= 本周已消耗
- `weekly_used`（API返回）= 本周剩余

**数据说明：**
- M2.7 配额数据完全可信（5h窗口 + 本周两个维度）
- 每周一 00:00 UTC+8 重置本周配额
- 5h 窗口每天滚动刷新
