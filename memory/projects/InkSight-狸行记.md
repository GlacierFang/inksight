# InkSight 狸行记（CUSTOM_MIAOLI）

## 一句话

喵狸的日漫一日。一次 LLM 写画面，一次生图出一张日漫图。屏上一句话都没有。

## 定位（2026-11-02 冰河大人定的）

冰河大人原话：「一个简单的给 prompt 出图的功能」「就是日漫，日漫！」

中间踩过的坑（都别再犯）：
- 第一版把「参考草地铺道蚁」读成了照抄草铺的版式 —— 屏上出现标题+四行正文+心声+状态
  那套文字模式，用户直接否掉：「这是日漫么？这是纯图片么？下面的文字是怎么回事？」
- 第二版自己加了对话气泡，理由是「日漫该有台词」。用户否掉：「不要对话不要气泡！」
- 第三版把草铺的参数（骰子、五档落点、状态轴、捡东西收集册）整个搬过来，
  变成「一只猫在执行我设计的旅行系统」。用户否掉：
  「我说参考草铺，是参考行为逻辑讲故事的方式，你把一堆参数也都拿过来了，这对么？」

结论：**草铺可以参考的是「行为逻辑讲故事的方式」，不是它的版式，更不是它的参数。**

## 屏上结构（照抄透屏）

- 状态栏隐藏
- 整版图 400×270 占满正文区（ART_DISPLAY = (400, 270)）
- 页脚「狸行记 | 喵狸·签名」（label + attribution_template）

## 版式：左右等宽双格（2026-11-02 冰河大人定）

冰河大人原话：「当然要了，动态感指的是画面本身。」

**双格在同一个图里**（一次生图出一页两格），不是两张图拼的。
好处：两格的猫必然是同一只，不用靠 prompt 凑一致性。

- 左右等宽，中间一条粗黑竖分隔线贯穿，两格带黑边框。不做非等分切入。
- 左格起势（蓄力、耳朵先动、盯住目标），右格爆发（扑、撞、钻、翻）。
- 两格姿势和视角必须明显不同：一格贴近平视，一格俯拍或仰拍拉远。
  踩过的坑：第一版两格都画成同一个蹲姿，看起来像同一张复制两份。

## 屏上结构（照抄透屏）

## 生图提示词（2026-11-02 第二版）

    {第一格分镜}
    {第二格分镜}
    {CAT_SPEC}       角色锚点 + 日漫猫画法（杏仁眼、尖下颌、细腰长腿）
    {PANEL_SPEC}     左右等宽双格 + 粗黑竖分隔线
    {MANGA_SPEC}     黑白日漫：粗勾线、网点纸、大留白
    {DYNAMIC_SPEC}   动感：斜切、集中线、速度线、飞溅、残影；两格姿势视角要不同
    {NEGATIVE_SPEC}  排除项：动物肖像插画/素描/3D/柔焦/水彩/绘本/静态坐姿/两格雷同/版权角标
                     另加：画面里不要有任何文字、气泡框、对话框、签名、水印，四个角落尤其干净

**LLM 层也改了**：DAY_PROMPT 现在要写两拍（第一格起势 / 第二格爆发），
不是写一句话。写一句话就画不出动感 —— 模型没有第二拍可以参考。

**第一版跑偏成素描插画**（冰河大人：「不是日漫风」「没有真正的动态感」）：
提示词只写了「粗勾线 + 网点纸 + 大留白」，模型理解成素描插画，
于是画了一张无边界的单幅肖像插画，猫正面坐着抬爪摆拍。
根因：没有给版式（分格）、没有给动效指令、没排除插画风格。
修法就是上面三段：PANEL_SPEC + DYNAMIC_SPEC + NEGATIVE_SPEC。

**为什么写「不要颜色」**：2 色屏 + Atkinson 抖动吃中间色和渐变，但日漫黑白分镜
（粗轮廓线 + 网点纸 + 大留白）恰好是 2 色屏的强项。所以提示词写黑白漫画，不写赛璐璐上色。

**为什么写「不要有任何文字、气泡框」**：模型画的字在 2 色屏上会糊成一团。
屏上的字和回顾页的字都由程序排。

**角色一致性锚点**（CAT_SPEC，每次复用同一段）：
额头 M 字纹、背上狸花条纹、尾巴梢一截白、右耳尖小缺口、
脖子上系项圈，项圈正中挂一枚圆形旧铜钱。

## 名字固定

CAT_NAME = "喵狸"，不让模型自封（第一版模型自封「山大王」，用户定的名字不能被覆盖）。
模型只出：标题、画面、签名。

签名去重：页脚是「喵狸·签名」，模型偶尔会写「喵狸来此一爪」，
拼起来变成「喵狸·喵狸来此一爪」—— _strip_name() 去掉开头重复的猫名。

## 教训

sibling-pattern-first-fix 已加 Step 0：区分「概念层」和「版式层」。
用户说「参考 X」时，先判断指的是哪一层 —— 照抄错的那层，就是给对的想法套错的外壳。

**写「日漫」两个字不等于给了日漫**：模型默认会画成素描插画。
日漫 = 分格页 + 网点纸 + 大留白 + 斜切构图 + 速度线 + 角色画法。
这几样要逐条写出来，还要显式排除插画风格。

**「动感」是画面属性，不是文字属性**：想让画动起来，
得先让 LLM 写两个时间点（起势 / 爆发），再把速度线和斜切构图写进生图提示词。
只写一句场景描述，模型给你一张摆拍。
