### 三、实现（新增两个模块）

**`backend/core/subscription.py`** — 订阅集合唯一真相源 + 闸门
- `get_snapshot()` 60 秒缓存；`ensure_allowed(mode_id, source=)` 抛 `ModeNotSubscribed`
- `allow_modes()` contextvar 通道：设备自己的勾选放行（设备就是在用设备）
- `active_macs()` / `active_device_configs()`：遍历在用设备各自勾选
- **必须用标准库 sqlite3 + `asyncio.to_thread`，不能用 `core/db.py` 的 aiosqlite** —— aiosqlite 连接绑定在创建它的事件循环上，跨循环（后端服务/批处理脚本/单测各一个循环）复用会死锁

**`backend/core/daily_cache.py`** — 每日内容缓存
- 键：图片 `daily:{模式}:{指纹}:{日期}:{画幅}`（存 `cache.db` 的 `image_cache` 表）；文字 `dailytext:{模式}:{指纹}:{日期}`（新表 `daily_text_cache`）
- 键**不含 mac** → 同参数多屏共享
- `get_or_generate()` 同键互斥（进程内 lock），拿到锁后再查一次
- `get_recent()` 取 7 天内最近一次成功的 —— 生成失败时的兜底，不需要额外降级链
- 同样用标准库 sqlite3（原因同上）

**闸门落点**：`core/pipeline.py` 的 `generate_and_render()` 和 `generate_content_only()` 两个外层入口。内部函数 `_generate_content_for_persona()` **不做**检查（每层查库会拖慢热路径、挂住单测）。

**接入点**：
- `api/shared.py` `build_image()`：设备路径先查日更缓存，命中即下发不发请求；读缓存也过闸门（未勾选连旧图都不下发），失败转 403
- `api/routes/render.py`：`/widget/{mac}`、`/api/routes/mobile.py` 小组件 —— 走 `allow_modes(device_modes)`
- `scripts/daily_content.py`：`_targets()` 按每台在用设备各自配置遍历，未勾选的跳过
- `scripts/tangping_daily.py` / `scripts/ant_daily.py`：开头查订阅集合，未订阅直接跳过

### 四、同时砍掉的两处烧 token 路径

- 重连时的 `content_cache.force_regenerate_all()` —— 短暂断网也要付一份全量生图的钱

### 五、踩过的坑（重要）

1. **aiosqlite 跨事件循环死锁** —— 把 DB 读放进原本无 DB 的管线路径后，单测直接挂住（pytest 无输出、faulthandler 也定位不到）。解法：标准库 sqlite3 + 线程池。
2. **`get_or_generate` 返回元组被当图片写缓存** —— `generate_fn` 返回 `(img, content)`，缓存只吃 img。单测暴露：`AttributeError: 'tuple' object has no attribute 'save'`。改成三元返回 `(img, content, fresh)`。
3. **`cacheable=false` 旧开关卡住日更缓存** —— 上一轮砍模式后 15/16 个模式标了 `cacheable=false`（只有 CUSTOM_DAILY_TRIO 是 true），日更读路径被 `is_mode_cacheable` 拦住，等于白做。**日更路径不再受 `is_mode_cacheable` 限制**（那个开关是给「按 mac 批量预热」用的，日更缓存已取代它）。
4. **删代码块要按结构匹配，不能按行号硬切** —— 第一版按行号删 WebApp 误删了 preview 页一个容器 div，webpack 报 `Unterminated regexp literal`。改用花括号配对 + 锚点匹配。
5. **正则删 import 行会漏掉列表里的引用** —— `re.sub(r'^.*\balbum\b.*$', '', s, flags=re.M)` 删了 `from .album import router as album_router` 却留下 `api_routers` 列表里的 `album_router,`，后端起不来。
6. **空 `CatalogItem(` 残留** —— 按行删块留下空壳，`TypeError: CatalogItem.__init__() missing 4 required positional arguments`。
7. **heredoc 会吞转义** —— `python3 - <<'PY'` 里的 `\n` 在多层嵌套 shell + heredoc 组合下会被吃掉，批量替换接连失败。**改用 `edit` 工具直接改文件**更可靠。
8. **删除模式后 `get_cacheable_modes()` fallback 仍是老集合**（`{"STOIC","ROAST","ZEN","DAILY"}`）—— 这些模式已不存在。
