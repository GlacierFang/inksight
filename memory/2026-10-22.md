## 修 /ink/ 重定向死循环（09:31 冰河大人才发现）

**现象**：外网 http://ruohan.site/ink/ → ERR_TOO_MANY_REDIRECTS（浏览器说删 Cookie，其实是死循环）

**根因**：nginx 与 Next.js 对尾斜杠期望相反
- Next.js `basePath=/ink`：`/ink/` → **308** → `/ink`（Next 不要尾斜杠）
- nginx `location = /ink { return 301 /ink/; }` → 又打回 `/ink/`
- → 无限互跳

**修法**（只动 nginx 一处，18 行）：
- `= /ink` → `proxy_pass http://127.0.0.1:18835`（直转，不跳）
- 新增 `= /ink/` → `proxy_pass http://127.0.0.1:18835/ink`（剥尾斜杠再转）
- 两个都要的原因：**浏览器会永久缓存旧的 301**，只修 `/ink` 的话老用户照样循环

**备份**：`/etc/nginx/backups/openclaw.bak.20261022-093316-inkredirect`

**验证**：
- `/ink/` 200、`/ink` 200、`/ink/zh` 200、zh 下 login/flash/config/preview/discover 全 200
- `/ink/api/health` 200、`/ink/api/firmware/releases` 200
- 页面真渲染：`<title>墨鱼AI墨水屏 | InkSight</title>`，105KB HTML
- 原站回归：`/` `/dashboard/` `/shanhe/` `/gallery/` `/nature/` `/studio/` `/knowledge/` `/train-app/` `/diary/` `/library/` 全 200
- nginx -t 通过，diff 确认只有这 18 行改动

**教训（写进 InkSight.md 坑 13-14）**：
1. 探活不能只探子路径 —— 我 09:03 探 `/ink/login` 200 就宣布通过，漏了 `/ink/` 根路径自己会跳
2. 每个部署必须探根路径 + 子路径，且用 `curl -L --max-redirs` 看真实跳转链
3. 反向代理下 nginx 和上游框架的尾斜杠规则可能相反 = 经典死循环

## 修注册报「网络错误」（10:00-10:25）

**根因**：昨天批量把 `fetch("/api/...")` 改成 `fetch(apiUrl(...))` 时**漏了 4 处**。浏览器把请求打到站点根 `/api/auth/register`（没有 `/ink` 前缀）→ nginx 返回 404 HTML → `res.json()` 抛错 → catch → 页面显示「网络错误」。后端和 nginx 一直是好的（`POST /ink/api/auth/register` 实测 200）。

**判据（这次学到的）**：
- `Link` / `router.push` / `router.replace` → Next 的 `dispatchNavigateAction` → `addBasePath()`，**自动加** `/ink`
- `fetch` / `window.location.href` / `window.open` → **不会自动加**，必须自己拼
- 推论：**`next` 查询参数里不能带 `/ink`**，它最终会走 `router.push(next)` 再被加一次 → `/ink/ink/zh/flash`（这个坑我改的时候自己踩了）

**改动**（11 处，diff 逐 hunk 核对过，只动预期行）：
- `app/login/page.tsx` 1 处：register/login endpoint 包 apiUrl
- `app/config/page.tsx` 5 处：import 加 siteUrl、3 处 window.location.href、1 处解绑 url
- `app/flash/page.tsx` 5 处：3 处 firmware endpoint、1 处 loginHref、1 处 next 参数去前缀

**验证**：tsc --noEmit 0 错误 → next build rc=0（BUILD_ID `JGCjgUABMO078LDK4FJuo`）→ 服务重启 active → **冰河大人自己注册成功**（库里有 `冷峻冰河`）→ 测试账号已清（剩 1 个真实账号）

## InkSight：修配对链路（16:00-16:20）
