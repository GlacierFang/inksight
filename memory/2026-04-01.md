# 2026-04-01 日记

## Dashboard 个人工作台 — 重新理解与重构

### 核心认知更新

这次对 Dashboard 的理解和之前不同了：

**1. 发布日历是日常操作入口，不是参考信息**
- 冰河大人不想通过微信/飞书对话框告诉我"今天要发什么、发了没有"
- 而是在日历里直接点击日期，标记「已发布」
- UI 上：点击日期 → 显示当天任务 → 点按钮标记 → 实时更新

**2. Sessions 标签的核心是区分"谁真的在工作"**
- 🟢 工作中（active）：5分钟内有活动
- 🔵 执行中（running）：agent/subagent 在跑
- ⚪ 空闲（idle）：无活动
- 不是"员工"——是智能体实例，按活跃度分

**3. Usage 页面核心是观察 Token 消耗趋势**
- 柱状图看每日调用量
- 饼图看来源分布
- 窗口配额一眼可见
